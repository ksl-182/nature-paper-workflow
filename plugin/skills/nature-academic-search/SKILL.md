# Academic Literature Search

Search and discover relevant academic literature.

## When to Use

- User needs to find relevant papers on a topic
- User wants to do a literature review
- User needs references for a manuscript section
- User asks to search academic databases

## How It Works

1. Understand the research topic and scope
2. Identify key search terms and synonyms
3. Search academic databases (Google Scholar, PubMed, etc.)
4. Evaluate relevance and quality of results
5. Summarize findings with key papers highlighted

## Search Strategy

- Start with broad terms, then narrow down
- Use Boolean operators (AND, OR, NOT)
- Check citation networks (forward and backward)
- Look for review papers for comprehensive overviews
- Check recent publications for cutting-edge findings
