# Citation and Reference Management

Format and manage academic citations and references.

## When to Use

- User needs to format citations in a specific style
- User wants to check or fix reference formatting
- User needs help with bibliography management

## How It Works

1. Identify the target journal's citation style
2. Format in-text citations correctly
3. Ensure reference list matches in-text citations
4. Check for completeness of reference metadata
5. Verify citation accuracy and consistency

## Citation Ethics

- Cite paper A for A's own data, methods, claims
- Cite paper B for B's interpretation or commentary on A
- Avoid leaning on secondary sources when the source article can be cited directly
- Acknowledge intellectual debt openly

## What Needs Citation

- Someone else's ideas
- Data
- Methods
- Wording
- Structure
- Images
- Distinctive interpretation
