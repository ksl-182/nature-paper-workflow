# Research Data Management

Create data availability statements and manage research data.

## When to Use

- User needs a data availability statement for a paper
- User wants to share research data
- User needs help with data documentation
- User asks about data repositories

## How It Works

1. Identify what data needs to be shared
2. Choose an appropriate repository
3. Write a clear data availability statement
4. Ensure proper data citation
5. Follow journal and funder requirements

## Data Availability Statement Template

"The data that support the findings of this study are available in [repository name] at [DOI/URL]. The data are available under [license]."

## Common Repositories

- Figshare
- Zenodo
- Dryad
- Mendeley Data
- Domain-specific repositories
