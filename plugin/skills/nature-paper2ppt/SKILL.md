# Paper to Presentation

Convert academic papers into presentation slides.

## When to Use

- User needs to present their research
- User wants to create slides from a paper
- User needs an academic presentation

## How It Works

1. Identify the key message and audience
2. Structure the presentation:
   - Title and motivation
   - Research question / hypothesis
   - Methods (brief)
   - Key results
   - Conclusions and implications
3. Design slides for clarity
4. Keep text minimal, visuals prominent

## Slide Structure

1. Title slide
2. Background / motivation (1-2 slides)
3. Research question (1 slide)
4. Methods overview (1-2 slides)
5. Key results (3-5 slides)
6. Discussion / conclusions (1-2 slides)
7. Future work (1 slide)
8. Acknowledgments (1 slide)

## Design Tips

- One key message per slide
- Use figures from the paper where appropriate
- Minimum 24pt font for body text
- Limit bullet points to 5 per slide
- Use consistent color scheme
