# Academic Manuscript Polishing

Polish, refine, and improve existing academic manuscript text.

## When to Use

- User wants to polish or refine academic writing
- User needs language editing for clarity and precision
- User wants to translate Chinese academic text to English
- User asks for improving sentence-level fluency

## How It Works

1. Read the manuscript section carefully
2. Identify areas for improvement:
   - Clarity of expression
   - Logical flow between sentences
   - Precision of scientific terminology
   - Grammar and syntax
   - Consistency of style
3. Preserve the original meaning and scientific content
4. Improve readability while maintaining academic rigor
5. Surface novelty (question 2) early — don't bury it behind methods detail

## Principles

- Never change the scientific meaning
- Maintain the author's voice and argument structure
- Follow journal-specific formatting requirements
- Flag any factual inconsistencies for the author to verify
