# Academic Paper Reader

Read, interpret, and summarize academic papers.

## When to Use

- User wants to understand a research paper
- User needs a paper summary or interpretation
- User wants to translate a paper
- User asks for help reading academic literature

## How It Works

1. Read the paper systematically:
   - Abstract for overview
   - Introduction for context
   - Results for findings
   - Discussion for interpretation
   - Methods for details
2. Answer the five reader questions:
   - Relevance: Is this for me?
   - Novelty: What is new here?
   - Trust: Do I believe it?
   - Reuse: Can I use it?
   - Meaning: What does it mean?
3. Summarize key findings and significance
4. Note limitations and open questions

## Output Format

- One-paragraph summary
- Key findings bullet points
- Limitations noted
- Suggested follow-up reading
