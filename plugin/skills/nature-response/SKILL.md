# Reviewer Response Letter

Draft point-by-point response letters to reviewer comments.

## When to Use

- User received reviewer comments and needs to respond
- User is revising a manuscript after peer review
- User needs help drafting a revision letter

## How It Works

1. Read each reviewer comment carefully
2. Categorize comments:
   - Major concerns (must address)
   - Minor suggestions (should address)
   - Editorial corrections (easy fixes)
3. Draft point-by-point responses
4. Show what was changed in the manuscript
5. Provide evidence or reasoning for disagreements

## Response Structure

```
Reviewer #1, Comment 1:
[Quote the comment]

Response:
[Your response, with specific references to changes made in the manuscript]
```

## Principles

- Be respectful and professional
- Address every comment, even minor ones
- Show concrete changes (quote revised text)
- Provide data or citations when disagreeing
- Thank reviewers for constructive suggestions
