# Nature-Style Academic Writing

Draft, restructure, and plan manuscript sections following Nature journal conventions.

## When to Use

- User wants to write or draft academic manuscript sections
- User asks for help with abstract, introduction, methods, results, discussion, or conclusion
- User needs to restructure existing manuscript content
- User asks for Nature-style scientific writing guidance

## How It Works

1. Understand the research context, target journal, and audience
2. Identify the core argument or finding
3. Structure content with clear logical flow following the reader question sequence:
   - Relevance: Is this for me?
   - Novelty: What is new here?
   - Trust: Do I believe it?
   - Reuse: Can I use it?
   - Meaning: What does it mean, and where are the boundaries?
4. Use concise, precise scientific language
5. Ensure proper citation integration

## Paper Type Detection

| Type | Definition |
|---|---|
| research | Reports a phenomenon, mechanism, or finding |
| methods | Proposes a new method or protocol |
| hypothesis | Establishes or rules out a causal explanation |
| algorithmic | Proposes a procedure, model, or system |
| review | Synthesizes the state of a field |

## Output

- Structured drafts with clear section headings
- Placeholder citations where needed
- Notes on areas requiring additional data
- Suggestions for clarity and impact

## Language Support

- Support both English and Chinese academic writing
- Adapt style based on target journal requirements
- Maintain consistent terminology throughout
